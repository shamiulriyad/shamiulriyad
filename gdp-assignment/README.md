# Assignment: Is GDP Growth an Adequate Measure of Economic Well-Being?

| File | Use it for |
| --- | --- |
| `GDP_Growth_and_Economic_Well-Being_Assignment.docx` | The full assignment. Open in MS Word, fill in the cover page, print or save as PDF. |
| `GDP_Growth_and_Economic_Well-Being_Assignment.pdf` | Preview copy (cover fields still show the [placeholders]). |
| `figures/` | All 17 charts and the cover image as PNG files. |
| `make_figures.py`, `content.py`, `build_assignment.py` | Rebuild everything: `python3 make_figures.py && python3 build_assignment.py` |

**Filling in the cover page:** click any `[bracketed]` text on the cover (teacher name, your name, ID, batch,
section, semester, course title and code, date) and type over it. The university name and department are
editable the same way.

**If you change the text:** right-click the Table of Contents (and the List of Figures / Tables) and choose
*Update Field → Update entire table* so the page numbers stay correct. Word may also ask to update fields
when the file opens; click *Yes*.

Layout: A4, Times New Roman 12 pt, a single navy colour, 31 pages in total (cover, abstract, contents,
lists of figures, tables and abbreviations, 23 pages of main text, references and a glossary).
