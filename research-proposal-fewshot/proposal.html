Sample-Guided, Rotation-Robust Few-Shot Anomaly Detection and Localization for Semiconductor Wafer Dies with Feedback-Driven Adaptation

Md Shamiul Islam Riyad · B.Sc. CSE, United International University · October 2026

1Problem statement

Fully supervised inspectors need many labelled examples of every defect type, yet a new product or process step yields few labelled defects, and defect types absent from training fall outside a closed-set classifier’s outputs. Learned features are also tied to the orientation, position and scale seen in training, so a rotated or shifted die can raise a false alarm or hide a defect, the motivation for registration-based few-shot methods [5, 6]. An image-level label does not say where the defect is, and pixel masks are costly to draw. Large public sets such as WM-811K are discrete wafer maps (one pass/fail cell per die), not die-surface images [7], so alone they cannot support pixel-level localization.

2Proposed solution

An engineer supplies K = 1–8 defect-free sample dies of the same design. Each new die is aligned to them and compared patch by patch in a pretrained feature space, giving an anomaly map and a decision: normal, known defect type or unknown anomaly. Engineer-verified decisions update the reference memory; an update is kept only if held-out results do not degrade.

3Research objectives

  1. Few-shot detection from K ≤ 8 normal references, no retraining.
  2. Rotation robustness to die rotation, shift, scale, illumination.
  3. Localization: pixel-level anomaly maps that match expert masks.
  4. Unknown anomalies kept apart from normal and known defect types.
  5. Verified feedback that improves later inspections, without forgetting.

4Proposed method

  • Geometric alignment: rotation, shift and scale vs. the references (feature matching + RANSAC or Fourier–Mellin); rotated references as fallback.
  • Pretrained features: frozen patch features, DINOv2 ViT or CNN [1, 4].
  • Memory & scoring: patch bank; nearest-neighbour distance per patch [4].
  • Localization: upsampled score map; τ set on held-out normals.
  • Optional classification: defect prototypes; far from all → unknown.

5Datasets · raw surface images and discrete wafer maps are different data, used for different questions

DatasetWhat it containsRole in this studyLimitations

core · semiconductor		 SEM images of unpatterned wafers (one layer); 4,591 images, 6 defect classes, expert binary masks. Core test of pixel localization and known classes; held-out classes act as unknowns. No repeated die layout or documented defect-free set (references from clean areas); licence unconfirmed.

wafer-level context		 Wafer maps, not images: 811,457 per-die pass/fail maps; 172,950 labelled (9 classes). Wafer-level few-shot and held-out-pattern tests; choosing which dies to inspect. No die-surface appearance and no pixel-level defect masks.
MVTec AD [9]
method check		 5,354 industrial images, 15 categories, pixel masks. Reproduce published baselines to check the implementation. Not semiconductor data; CC BY-NC-SA 4.0.

Gap: no public, mask-annotated image set of patterned dies was found; rotation tests use rotated copies plus a small synthetic die set, reported as synthetic.

6Evaluation plan

  • Detection: image AUROC, AUPR, false-alarm rate at 95 % recall.
  • Localization: pixel AUROC, AUPRO, IoU/Dice at τ.
  • Few-shot: K = 1, 2, 4, 8; 5 random reference draws, mean ± s.d.
  • Rotation: 0–360° (15° steps), shift, ±10 % scale; ± alignment.
  • Unknown: leave-one-class-out; unknown-detection AUROC.
  • Feedback: simulated stream incl. wrong labels; gain, forgetting.
  • Baselines: PatchCore [4], RegAD [5], GraphCore [6], AnomalyDINO [1], UniVAD [10], IC segmentation [2]; supervised U-Net as upper bound.

7Expected contribution (hypotheses, to be validated)

H1At K ≤ 8, alignment plus rotated references reduces the accuracy loss under die rotation versus the same memory without alignment.

H2Verified feedback written to the memory improves later localization without retraining or forgetting.

vs. prior workMemory scoring [1, 4], registration [5], rotation-invariant features [6] and feedback memory correction [3] (MVTec AD, simulated feedback) exist separately. New here is their joint, reproducible test on semiconductor SEM data under rotation, open-set and feedback conditions; negative results count too.
