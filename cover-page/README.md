# DIU BBA Cover Page

An editable assignment cover page for Dhaka International University (BBA).

| File | Use it for |
| --- | --- |
| `DIU_BBA_Cover_Page.html` | Open in Chrome or Edge. Click any text to edit it, change the colour, add or remove rows, upload the official logo, then press **Print / Save PDF** (choose A4, margins "None"). Your edits are saved in that browser. |
| `DIU_BBA_Cover_Page.docx` | The same design for MS Word / Google Docs. Replace the grey hint text with your details. |
| `Sample_Filled_Cover_Page.pdf` | Example of a filled-in page (sample details only). |
| `build_docx.py` | Rebuilds the Word file: `python3 cover-page/build_docx.py` |

Leave a field empty in the HTML version and it prints as a blank line you can fill in by hand.
The round "DIU" seal is a simple monogram; click it to replace it with the official university logo.
