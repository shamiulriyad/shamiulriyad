## N.5 Glossary

| Term | Meaning |
|---|---|
| Abstention | Declining to output a value at a pixel because evidence is insufficient; recorded in mask $A$. |
| AUSE | Area under the sparsification error curve: how well uncertainty ranks errors. |
| AU-PRO | Area under the per-region-overlap curve, a threshold-free segmentation metric. |
| Breakdown point | Fraction of outliers an estimator tolerates before it can be arbitrarily wrong (median: 50%). |
| Die-to-die inspection | Comparing a die image with images of neighbouring dies of the same design. |
| ECC | Enhanced correlation coefficient registration [27]. |
| Golden die / reference | A die image verified to be defect-free, used as reference. |
| Hallucination | Plausible structure produced by a model that is not supported by the measurements. |
| MAD | Median absolute deviation, a robust spread estimate. |
| Provenance map | Per-pixel record of which dies contributed to the reconstructed value. |
| ROI | Region of interest common to all images. |
| SEM | Scanning electron microscope. |
| Support $S(\mathbf{x})$ | Number of reliable observations at a pixel. |
| Systematic defect | A defect repeated at the same location on many or all dies (e.g. from the mask or design). |
| TRE | Target registration error: distance between estimated and true mapped points. |
| Wafer map | Grid of per-die categorical results; not an image of the die surface. |
